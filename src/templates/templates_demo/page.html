{# ---------- 2. For + divisibleby ---------- #}

Ciclo for + forloop.counter|divisibleby

Los renglones cuyo número de iteración es divisible entre {{ divisible_by }} se marcan como "Par".

{% for product in products %}
{{ forloop.counter }}. {{ product.name }} {% if forloop.counter|divisibleby:divisible_by %} Par {% else %} Impar {% endif %} ${{ product.price|floatformat:2 }}
{% endfor %}
